# Вычислительная физика с Python — мини-курс для 10–11 классов

Четыре занятия по 3 астрономических часа для учеников физико-математических школ. На каждом занятии одна школьная физическая задача решается несколькими способами: аналитически, численно, через случайные числа или по экспериментальным данным.

| | Тема | Физика | Методы |
|---|---|---|---|
| 1 | [Python как лабораторный инструмент](lesson-01/) | фотоэффект (опыт Милликена), маятник, насыщенный пар | numpy, matplotlib, МНК, интерполяция |
| 2 | От параболы к реальному мячу | бросок под углом, сопротивление воздуха | sympy, метод Эйлера, `solve_ivp`, метод стрельбы |
| 3 | Электрические цепи | правила Кирхгофа, бесконечные цепочки, лампа и диод в цепи | системы линейных уравнений, итерации, метод Ньютона |
| 4 | Из хаоса — закон | идеальный газ, распределение Максвелла, броуновское движение | случайные числа, метод Монте-Карло |

## Запуск

```bash
pip install -r school/requirements.txt
jupyter lab
```

Ноутбуки читают данные из общей папки `data/` по относительным путям, поэтому Jupyter Lab нужно запускать из корня репозитория.

## Структура занятия

- `NN-*.ipynb` — ноутбук для учеников;
- `NN-*-solutions.ipynb` — решения;
- `slides.md` — слайды в формате [Marp](https://marp.app/) с заметками докладчика в HTML-комментариях. Просмотр — расширение «Marp for VS Code», экспорт в PDF — `npx @marp-team/marp-cli slides.md --pdf`;
- `plan.md` — хронометраж и подготовка к занятию;
- `build_notebooks.py` — генератор обоих ноутбуков (правки вносятся в него), `make_figures.py` — рисунки для слайдов.
